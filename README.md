# is-123-java-shpidonov
Курсовая работа по Java по теме создание HTTP сервера по проведению опросов.
будет реализованна логикак регистрации/авторизации, функции создания, редактирования и удаления опросов и входящих в них вопросов. Также реализация прохождения опросов, и сбор статистики с опросов, статистика может быть представленна на основе ответов конкретного пользователя или по всем пользователям ответившим на вопросы данного опроса(в виде графиков), реализация ролевой модели админ-пользователь-гость.
Сделана студентом группы ИС-123 Шпидонов Никита Алексеевич.

Прикладная разработка на Java 3 курс.2026 год
